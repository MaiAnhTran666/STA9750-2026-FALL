Green Transit Alliance: 2026 Green Transit Awards

Introduction

Every year, the Green Transit Alliance (GTA) recognizes the US public transit agencies that do the most to keep carbon out of the atmosphere. Public transit is often described as “green” by default, but not all systems are created equal: a diesel bus fleet in a coal-heavy state and an electric light-rail line in a hydro-powered one can have very different climate footprints per rider.

To compare agencies fairly, this year’s awards rely on the GTA Value Index, which combines three federal data sources: the EIA State Electricity Profiles (how clean each state’s electricity is), the National Transit Database (NTD) Energy Consumption report (how much of each fuel every agency burns), and the NTD Service report (how many trips and passenger miles each agency delivers). By joining these tables, we can estimate the CO₂ emitted per trip and per passenger mile for every agency in the country.

Data Acquisition

We draw on three public federal datasets. All downloads are cached locally in data/mp02 so the analysis can be re-run without repeatedly querying the source servers.

get_eia_sep <- function(state, abbr){
    library(tidyverse)
    library(stringr)
    library(httr2)
    library(rvest)
    library(fs)
  
    state_formatted <- str_to_lower(state) |> str_replace_all("\\s", "")
    
    dir_name <- fs::path("data", "mp02")
    file_name <- fs::path(dir_name, state_formatted)
    
    fs::dir_create(dir_name, recurse=TRUE)
    
    if(!fs::file_exists(file_name)){
        BASE_URL <- "https://www.eia.gov"
        RESPONSE <- request(BASE_URL) |> 
          req_url_path("electricity", 
                       "state", 
                       state_formatted) |>
          req_headers(
            `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0"
            ) |>   
          req_retry(
                max_tries = 4, 
          ) |>
          req_perform(file_name)
    
        resp_check_status(RESPONSE)
    }
    
    TABLE <- read_html(file_name) |> 
        html_element("table") |> 
        html_table() |>
        mutate(Item = str_to_lower(Item))
    
    if("U.S. rank" %in% colnames(TABLE)){
        TABLE <- TABLE |> rename(Rank = `U.S. rank`)
    }
    
    CO2_MWh <- TABLE |> 
        filter(Item == "carbon dioxide (lbs/mwh)") |>
        pull(Value) |> 
        str_replace_all(",", "") |>
        as.numeric()
    
    PRIMARY <- TABLE |> 
        filter(Item == "primary energy source") |> 
        pull(Rank)
    
    RATE <- TABLE |>
        filter(Item == "average retail price (cents/kwh)") |>
        pull(Value) |>
        as.numeric()
    
    GENERATION_MWh <- TABLE |>
        filter(Item == "net generation (megawatthours)") |>
        pull(Value) |>
        str_replace_all(",", "") |>
        as.numeric()
    
    data.frame(CO2_MWh               = CO2_MWh, 
               primary_source        = PRIMARY,
               electricity_price_MWh = RATE * 10,
               generation_MWh        = GENERATION_MWh, 
               state                 = state, 
               abbreviation          = abbr
    )
}

EIA_SEP_REPORT <- map2(state.name, state.abb, get_eia_sep) |> list_rbind()

load_ntd_energy <- function(){
  library(readxl)
  library(httr2)
  library(tidyverse)
  library(fs)
  
  DATA_DIR <- fs::path("data", "mp02")
  fs::dir_create(DATA_DIR, recurse=TRUE)

  NTD_ENERGY_FILE <- fs::path(DATA_DIR, "2025_ntd_energy.xlsx")

  if(!fs::file_exists(NTD_ENERGY_FILE)){
    request("https://www.transit.dot.gov/") |>
      req_url_path("sites",
                   "fta.dot.gov",
                   "files",
                   "2026-09",
                   "2025 Energy Consumption_260806.xlsx") |> 
      req_headers(
        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |> 
      req_perform(NTD_ENERGY_FILE)
  }
  
  if(file.info(NTD_ENERGY_FILE)$size < 1e4){
        cat("I was unable to download the NTD Energy File. Please try again.\n")
        stop("Download failed. Please delete the corrupted file by running `unlink('data/mp02/2025_ntd_energy.xlsx')` and try again.")
    }

  to_numeric_fill_0 <- function(x){
    x <- if_else(x == "-", NA, x)
    replace_na(as.numeric(x), 0)
  }

  read_excel(NTD_ENERGY_FILE) |> 
    select(-c(`Reporter Type`, 
              `Reporting Module`, 
              `Gallons of Other Fuel`, 
              `Other Fuel Description`)) |>
    mutate(across(-c(`Agency Name`, 
                     `Mode`,
                     `TOS`), 
                  to_numeric_fill_0)) |>
    group_by(`NTD ID`, `Mode`, `Agency Name`) |>
    summarize(across(where(is.numeric), sum), 
              .groups = "keep") |>
    mutate(ENERGY = sum(c_across(c(where(is.numeric))))) |>
    filter(ENERGY > 0) |>
    select(-ENERGY) |>
    ungroup()
}

NTD_ENERGY <- load_ntd_energy()

load_ntd_service <- function(){

      req_url_query(`$query`=paste(

        "`max_reporter_type` AS `reporter_type`",
        "`max_organization_type` AS `organization_type`",
        "`max_city` AS `city`",
        "`max_state` AS `state`",
        "`mode`",
        "`type_of_service`",
        "`max_primary_uza_code` as `uza_code`",
        "`max_primary_uza_name` as `uza_name`",

        "`sum_unlinked_passenger_trips_upt` as `total_upt`",
        "`sum_passenger_miles` WHERE caseless_one_of(`report_year`, '2025') limit 50000",

        `User-Agent` = "Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:149.0) Gecko/20100101 Firefox/149.0") |>

New York City dominates the ridership rankings. Across all of its modes, the average trip on MTA New York City Transit covers about 3.2 miles, a short distance that reflects the density of the city it serves. ## Estimating Emissions

To compare agencies, we first need to estimate how much CO₂ each one emits. We join the three datasets so that every row represents one agency operating one mode of transit, together with its fuel use, its ridership, and the carbon intensity of its state’s electricity grid.

Combustion fuels are converted to CO₂ using the EIA’s published emissions coefficients. Electricity is converted using each state’s average emissions per MWh, so an electric train in Washington (largely hydro) is credited with far lower emissions than the same train in West Virginia (largely coal). A few simplifying assumptions are needed:

  • Compressed natural gas is reported in gasoline-gallon equivalents (≈126.67 cubic feet of gas each); liquefied natural gas is converted at ≈82.6 cubic feet per gallon.
  • Bio-diesel is treated as conventional diesel, a conservative choice.
  • Ethanol and hydrogen are treated as zero-emission at the point of use, following the EIA’s treatment of ethanol as non-emissive.
Code 
# lbs CO2 per unit, EIA Carbon Dioxide Emissions Coefficients (2024)
CO2_LBS <- c(
  diesel     = 22.45,   # per gallon
  gasoline   = 18.73,   # per gallon, finished motor gasoline
  propane    = 12.68,   # per gallon, used for LPG
  kerosene   = 21.78,   # per gallon
  residual   = 24.78,   # per gallon, used for bunker fuel
  natgas_mcf = 120.85   # per 1,000 cubic feet
)
SCF_PER_GGE_CNG <- 126.67
SCF_PER_GAL_LNG <- 82.6

EMISSIONS <- NTD_ENERGY |>
  inner_join(SERVICE_BY_MODE,
             join_by(`NTD ID` == NTD_ID, Mode == mode)) |>
  inner_join(EIA_SEP_REPORT |> select(abbreviation, CO2_MWh),
             join_by(state == abbreviation)) |>

    elec_kwh = `Kilowatt hours of Electric Battery` +
               `Kilowatt hours of Electric Propulsion`,
    emissions_lbs =
      `Gallons of Diesel Fuel`             * CO2_LBS[["diesel"]] +
      `Gallons of Bio-Diesel`              * CO2_LBS[["diesel"]] +
      `Gallons of Gasoline`                * CO2_LBS[["gasoline"]] +
      `Gallons of Liquified Petroleum Gas` * CO2_LBS[["propane"]] +
      `Gallons of Kerosene`                * CO2_LBS[["kerosene"]] +
      `Gallons of Bunker Fuel`             * CO2_LBS[["residual"]] +
      `Gallons of Compressed Natural Gas`  * SCF_PER_GGE_CNG / 1000 * CO2_LBS[["natgas_mcf"]] +
      `Gallons of Liquified Nat Gas`       * SCF_PER_GAL_LNG / 1000 * CO2_LBS[["natgas_mcf"]] +
      elec_kwh / 1000 * CO2_MWh,
    emissions_tons = emissions_lbs / LBS_PER_METRIC_TON
  )

Normalizing Emissions by Service

A large agency will almost always emit more than a small one, so total emissions are not a fair basis for an award. Instead, we measure efficiency: how much CO₂ an agency emits per trip (unlinked passenger trip, UPT) and per passenger mile travelled. Because ridership is reported for the agency as a whole, we sum emissions and service across all of an agency’s modes.

To keep the comparison fair, we exclude records the NTD flags as likely inaccurate, agencies with fewer than 100,000 annual trips, and agencies with no recorded emissions (which usually signals missing fuel data rather than truly zero-carbon service). We then group agencies into three size classes so that small rural systems are not judged against the New York City subway.

Code 
AGENCY_EMISSIONS <- EMISSIONS |>
  filter(!flagged) |>
  group_by(`NTD ID`, `Agency Name`, state) |>
  summarize(emissions_lbs = sum(emissions_lbs),
            upt           = sum(upt),
            pmt           = sum(pmt),
            elec_kwh      = sum(elec_kwh),
            .groups = "drop") |>
  filter(upt >= 1e5, pmt > 0, emissions_lbs > 0) |>
  mutate(
    lbs_per_upt = emissions_lbs / upt,
    lbs_per_pmt = emissions_lbs / pmt,
    size = case_when(upt < 1e6 ~ "Small",
                     upt < 2e7 ~ "Medium",
                     TRUE      ~ "Large") |>
           factor(levels = c("Small", "Medium", "Large"))
  )

SIZE_SUMMARY <- AGENCY_EMISSIONS |>
  group_by(size) |>
  summarize(n_agencies = n(),
            median_lbs_per_upt = median(lbs_per_upt),
            median_lbs_per_pmt = median(lbs_per_pmt))

Award Winners

Greenest Transit Agency

The Greenest Transit Agency award goes to the agency in each size class with the lowest CO₂ emissions per passenger mile, the metric that best reflects the climate cost of actually moving people from place to place.

Code 
GREENEST <- AGENCY_EMISSIONS |>
  group_by(size) |>
  slice_min(lbs_per_pmt, n = 1) |>
  ungroup() |>

The Carbon Clunker Award

Not every agency deserves a trophy. Our Carbon Clunker Award goes to the medium or large agency with the highest CO2 emissions per passenger mile, the system where each mile of travel carries the heaviest carbon cost.

This year’s Carbon Clunker is City of Glendale (CA), which emits 3.32 lbs of CO2 per passenger mile, about 3.5 times the median for medium and large agencies (0.95 lbs).

Glendale’s problem is not an unusually dirty fuel but an unusually short trip. Its riders travel only about 1.6 miles per trip on average, so the fuel burned by each bus is spread across very few passenger miles. The lesson for local circulator services is clear: short routes with light ridership are where electrification would pay the biggest climate dividend.

Green Transit Alliance Names 2026’s Greenest Transit Agencies; Pacific Northwest Leads the Way

New York, NY — The Green Transit Alliance (GTA) today announced the winners of its annual Green Transit Awards, recognizing the US public transit agencies that move riders with the smallest carbon footprint.

Winners were selected using the GTA Value Index, which combines 2025 fuel and electricity use from the National Transit Database with state-level power-grid emissions data from the US Energy Information Administration. Each agency’s total CO₂ emissions were divided by the passenger miles it delivered, rewarding agencies that move people efficiently rather than simply rewarding small ones.

Greenest Transit Agency, Large: Tri-County Metropolitan Transportation District of Oregon (OR) emitted just 0.097 lbs of CO₂ per passenger mile, 7 times cleaner than the typical large agency.

Greenest Transit Agency, Medium: City of Seattle (WA) posted the best score in the entire country at 0.064 lbs of CO₂ per passenger mile, 15.8 times cleaner than its peers.

Greenest Transit Agency, Small: Adirondack Transit Lines, Inc. (NY) earned top marks at 0.146 lbs of CO₂ per passenger mile, 9.8 times cleaner than the median small agency.

Carbon Clunker Award: At the other end of the scale, City of Glendale (CA) recorded 3.32 lbs of CO₂ per passenger mile, 3.5 times the median for medium and large agencies, driven by very short average trips.

“Public transit is a climate solution, but only when it is run on clean power and used efficiently,” said the GTA Executive Director. “This year’s winners show what is possible when electric service meets a clean grid.”
